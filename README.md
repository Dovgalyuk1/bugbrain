# BUG BRAIN ($BBRAIN)

Static one-page site. No build step — open `index.html`.

**Idea:** pick one of 20 insect brains, it plugs into a trading terminal and starts calling trades.
You only decide whether to let each signal cook or swat it. 8 signals per session.

- `index.html` — everything (inline CSS/JS)
- `assets/` — brain image, 20 insect brain sprites, favicon

Edit the SETTINGS block at the top of the script to set `CONTRACT`, `TWITTER`, `BUY_URL`.
