# NEUROFLY ($NFLY)

Static one-page site. No build step — open `index.html`.

**Idea:** twenty AI trading agents, each one running on the mapped brain of a different insect.
Deploy an agent and it takes the terminal and starts calling trades; you decide whether to let
each signal cook or swat it. Eight signals per session.

- `index.html` — everything (inline CSS/JS)
- `fly.webp` — the hero fly
- `b-*.webp` — the 20 agent portraits
- `favicon.png`

Edit the SETTINGS block at the top of the script to set `CONTRACT`, `TWITTER`, `BUY_URL`.
